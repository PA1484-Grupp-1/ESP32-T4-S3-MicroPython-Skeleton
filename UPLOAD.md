# Upload Guide

1. Hold down `BOOT` then **Press** `RST` (They are the same button) to go into Upload mode
2. Open PlatformIO Extension Tab (On the far left)
3. Project Tasks > t4s3-micropython > Custom (Wait for the Project to initialize, Loading bar bottom Left)
4. Build Python application
5. Flash Python application (Firmware is LVGL Library, Deploy runs both Firmware and Application Upload)
6. Press and Hold `RST` for 3 seconds to start the Application
