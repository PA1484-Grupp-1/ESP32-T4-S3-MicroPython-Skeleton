## Introduction
This project is based on the ESP32-T4-S3 LilyGO board. It uses MicroPython and LVGL to develop applications with a graphical user interface. The original skeleton-template repository has been extended with a bus departure application that displays real-time public transport information. It uses Trafiklab Realtime API to get public transport departures data.

This solution aims to provide users with a seamless and intuitive way to navigate Karlskrona's public transport network, making journey planning and accessing travel information easier and more effecient. 

*For more detailed information about the project's development, see [docs/index.md](./docs/index.md)*

## Building and running
### Uploading to the ESP32
To build and upload to the ESP32, the device needs to be connected to a computer. Hold down BOOT and the press RST to go into upload mode. In Visual Studio Code, open PlatformIO extension tab and navigate to **Project Tasks > t4s3-micropython > Custom**. The extension will take some time to load, wait for it to be ready. If this is the first time uploading the program to the device then the firmware must also be uploaded. Use the **Deploy complete project** action to build and upload both the firmware and application. Otherwise use the **Flash Python application** to build and upload only the program. Finally hold RST for a 3 seconds to restart the device and start the application.

*A step by step abridged version of these instructions are also available, see [UPLOAD.md](./UPLOAD.md)*

### Startup Procedure
To start the device it needs to be connected by USB-C to a power source. Once connected the device starts automatically.

### Arguments
The `secrets_env.py` file should contain WiFi connection information as well as API keys for Trafiklab.se. The template for it can be generated by running the `create_secrets.bat` script.

### Operational Guide
To operate, the device needs to be at minimum connected to a power source and preferably WiFi to be able to utilize all features. Turn on the device and swipe down to bring up the departures screen.

To change the stations, swipe right then press on the station tab. Search for a station using the on screen keyboard. The keyboard can switch between upper- and lowercase by pressing the up arrow. To clear all text press the X button. To Hide the keyboard press the checkmark button. You can bring the keyboard back by pressing on the station tab again. The dropdown below the search area shows all available stations matching the search arguments. Clicking on one of the options selects that station. The transport dropdown sets what type of transport to display. Changing either the station or transport refreshes the departures following the configuration. The initial configuration is the default settings. Pressing the save to default button overwrites the default configuration with the current configuration. Restoring to default restores to the saved default settings. Departures are refreshed automatically every 60 seconds but can also be manually refreshed using the refresh button on the departures screen.

Swiping left from the departures screen switches to the journey screen. The from and to tabs work the same way as departures station selection. Selecting two different stations will show the best possible journey based on arrival times between the two stations. Pressing the refresh button will query and show the new best possible journey. The journey in the middle of the screen is broken down into several steps with instructions on how to reach one station from the other.
